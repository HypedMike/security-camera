Security Camera

Turn any Linux machine with a webcam into a motion-detecting security camera, controlled entirely from Telegram.

View on GitHub Get started

Features

Motion detection

Learns what the empty scene looks like and alarms when a moving blob is large enough, even small or far from the camera. A simpler frame-difference detector can be switched in from Telegram.

GIF alerts

Every alarm arrives in Telegram as a tiny low quality GIF with a timestamp and a code; send /hd <code> for the full quality one. Rate-limited to one alarm every 5 seconds.

Bot commands

Ask for a snapshot, check machine status, or update the program, only from your configured chat.

Live graph

Optional web page plotting the motion score in real time to help tune the threshold.

Telegram commands

CommandDescription
/snapSends the next camera frame as a photo
/infoReports machine state and camera/alarm state
/hd <code>Sends the HD version of the alarm GIF with that code
/updatePulls the latest code, rebuilds and restarts
/pauseStops sending alarms
/resumeStarts sending alarms again
/edit_config [json]Sends all the settings as JSON; send it back with /edit_config in front to change them until the next restart

Get started

You need Linux with a V4L2 webcam, Go 1.24+, a C toolchain, and a bot token from @BotFather.

sudo apt install build-essential linux-libc-dev
git clone https://github.com/HypedMike/security-camera
cd security-camera
./build_linux
./securitycamera

On first run it asks for your bot token and chat id, lets you pick a camera, and saves everything to .env.

Configuration

VariableDescription
TELEGRAM_BOT_TOKENBot token (required)
TELEGRAM_CHAT_IDChat the bot talks to (required)
DETECTORMotion detector: background (default) or difference
BACKGROUND_THRESHOLDMoving blob area from 0 to 1 that triggers an alarm, default 0.003
DIFFERENCE_THRESHOLDFrame difference from 0 to 1 that triggers an alarm, default 0.05 (formerly ALARM_THRESHOLD)
CAMERA_IDCamera to use; saved on first run
LIVE_STREAM_GRAPHServe the live graph on port 8080
PRINT_DIFFERENCESLog each frame's motion score
PRINT_ALARMSLog each alarm that is set off

Keep your Telegram chat private: anyone in it can run /update. Full docs in the README.
